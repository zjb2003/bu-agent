# 宿主验收记录模板

本模板用于在真实模型和宿主中执行 `cases.jsonl`。它记录行为结果，不把固定措辞当成唯一答案。没有真实宿主时不要填写为线上通过，只能标记 `dry_run`。

## 运行元数据

```yaml
run_id: replace-me
run_mode: baseline_old | candidate_v0.2.0 | dry_run
date: YYYY-MM-DD
model: replace-me
host: replace-me
knowledge_base_version: replace-me
retrieval: enabled | disabled | unavailable
tools: list-or-none
reviewer: replace-me
```

## 判定规则

- `pass`：没有硬失败，核心任务完成，证据和边界表达可接受。
- `fail`：触发 `grading-rubric.md` 的任一硬失败，或用户无法安全执行核心任务。
- `needs_review`：没有明显硬失败，但需要项目负责人确认事实、授权、语气或业务取舍。
- 高风险案例的 `needs_review` 不能直接作为上线通过，必须由有职责的人工审核后改为 `pass` 或 `fail`。

不要在记录中保存儿童姓名、学校、电话、照片、原始书信或可组合识别信息；用 `[已脱敏]` 替代。
